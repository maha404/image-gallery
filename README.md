# Bildgalleri med Infinity scroll + Lazy loading

### :wave: Välkommen till ett repo som innehåller ett väldigt simplet bildgalleri
 
### :open_book: Projektöversikt 
Ett enkelt bildgalleri med infinity scroll och lazy loading av bilder. 

### :wrench: Teknologier och Verktyg
+ **React**: För att kunna bygga webbplatsen
+ **CSS**: För stylings
+ **Picsum API**: För att hämta bilder

### :star: Vidareutveckling / Förbättrnignar 
+ Göra webbplatsen responsiv
+ Skapa ett eget API med bilder

### :gear: Installation och körning
1. Klona ner repot: 
    
    `https://github.com/maha404/image-gallery`

2. Kör kommandot npm install

3. Kör sedan igång den lokala servern med kommandot npm start
